Problem 12: Geometric Analysis

Part a) Configuration Analysis

Given conditions:

  • T = 1300K
  • pA = 10pB
  • 60:40 atom %
\[\frac{60}{40} = \frac{\Phi_A}{\Phi_B}\]

Configuration parameters:

  • h = 50cm
  • Base width = 100cm
  • rA = \[\sqrt{(x-50)^2 + 50^2}\]
  • rB = \[\sqrt{(x+50)^2 + 50^2}\]
\[\frac{60}{40} = \frac{3}{2} = \frac{\Phi_A}{\Phi_B} = \frac{p_A}{p_B} \cdot \frac{r_B^2}{r_A^2} \cdot \frac{\cos \theta_A}{\cos \theta_B} = \frac{p_A}{p_B} \cdot \frac{r_B^3}{r_A^3}\]
Geometric Flux Ratio
\[\frac{3}{2} = 10 \frac{r_B^3}{r_A^3} \Rightarrow x = -34.7\text{ cm}\]
Solution

Part b) Enthalpy Analysis

Given conditions:

  • T = 1500K
  • pA = 15pB
\[\ln\left(\frac{p(T)}{p_B}\right) = -\frac{\Delta H}{RT}\]
\[\frac{\Delta H_B}{RT} - \frac{\Delta H_A}{RT} = \frac{\Delta(\Delta H)}{RT} = \ln\left[\frac{p_A/p_{B,A}}{p_B/p_{B,B}}\right] = \ln\left[\frac{p_A}{p_B} \cdot \frac{p_{B,B}}{p_{B,A}}\right]\]

For T = 1300K: ln(10) + c = ΔH/(R·1300K)

For T = 1500K: ln(15) + c = ΔH/(R·1500K)

\[\Delta(\Delta H) = -32.8\text{ kJ/mol}\]
