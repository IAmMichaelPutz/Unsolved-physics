Aufgabe 4

Bestimmen Sie die folgenden Grenzwerte:

$$\text{a) } \lim_{n\to\infty} \frac{3n^2 - 2n + 7}{4n^2 + 2}$$ $$\text{b) } \lim_{n\to\infty} \frac{(n^n + 2n! - 2^{n+3})^2}{n^22^{2n} - 3n2^n}$$ $$\text{c) } \lim_{n\to\infty} \sqrt{n}(\sqrt{n+1} - 1)$$

Lösung

Zu a): Für alle $n \in \mathbb{N}$ gilt

$$\frac{3n^2 - 2n + 7}{4n^2 + 2} = \frac{3 - \frac{2}{n} + \frac{7}{n^2}}{4 + \frac{2}{n^2}}$$

Der Zähler konvergiert nach mehrfacher Anwendung der Regel über den Grenzwert einer linearen Kombination von Folgen gegen

$$\lim_{n\to\infty} 3 - \frac{2}{n} + \frac{7}{n^2} = \lim_{n\to\infty} 3 - 2\lim_{n\to\infty} \frac{1}{n} + 7\lim_{n\to\infty} \frac{1}{n^2} = 3 - 0 + 0 = 3$$

Der Nenner konvergiert gegen

$$\lim_{n\to\infty} 4 + \frac{2}{n^2} = \lim_{n\to\infty} 4 + \lim_{n\to\infty} \frac{2}{n^2} = 4 + 0 = 4$$

Nach der Quotientenregel gilt

$$\lim_{n\to\infty} \frac{3n^2 - 2n + 7}{4n^2 + 2} = \lim_{n\to\infty} \frac{3 - \frac{2}{n} + \frac{7}{n^2}}{4 + \frac{2}{n^2}} = \frac{3}{4}$$

Zu b): Das am schnellsten wachsende Element im Nenner ist vermutlich $n2^n$. Deshalb erweitern wir den Bruch mit $\frac{1}{n2^n}$ für alle $n \in \mathbb{N}$ groß genug:

$$\frac{(n^n + 2n! - 2^{n+3})^2}{n^22^{2n} - 3n2^n} = \frac{1}{n2^n} \frac{(n^n + 2n! - 2^{n+3})^2}{n2^n - 3} = \frac{(\frac{n^n}{n2^n} + \frac{2n!}{n2^n} - \frac{2^{n+3}}{n2^n})^2}{\frac{n2^n}{n2^n} - 3}$$

Der Grenzwert des Zählers ist

$$\lim_{n\to\infty} (1 + 2\lim_{n\to\infty} \frac{n!}{n2^n} - 8\lim_{n\to\infty} \frac{2^n}{n2^n})^2 = (1 + 2 \cdot 0 - 8 \cdot 0)^2 = 1$$

wobei Ergebnisse der vorherigen Aufgabe benutzt wurden. Im Nenner interessiert uns der Term

$$\frac{n2^{2n}}{n2^n} = 4 \frac{2^{2(n-1)}}{2^{2(n-1)}} = 4$$

für $n \geq 2$. Da

$$\lim_{n\to\infty} 4 \frac{2^{n-1}}{(n-1)^{n-1}} = 4\lim_{n\to\infty} \frac{2^n}{n^n} = 4(0)^2 = 0$$

gilt nach der Behauptung 1

$$\lim_{n\to\infty} \frac{n2^{2n}}{n2^n} = 0$$

Deshalb ist der Grenzwert des Nenners

$$\lim_{n\to\infty} \frac{n2^{2n}}{n2^n} - 3 = 0 - 3 = -3$$

Nach der Quotientenregel gilt

$$\lim_{n\to\infty} \frac{(n^n + 2n! - 2^{n+3})^2}{n^22^{2n} - 3n2^n} = \frac{1}{-3}$$

Zu c): Wir setzen

$$x := \sqrt{n+1} - 1 = \frac{n+1-1}{\sqrt{n+1} + 1} = \frac{n}{\sqrt{n+1} + 1} \geq 0$$

Wenn $n \geq 3$, dann

$$n = (x + 1)^n = \sum_{k=0}^n \binom{n}{k} x^k \geq \binom{n}{3} x^3 = \frac{n(n-1)(n-2)}{6} x^3 \geq \frac{n^3}{3^3} x^3$$

Weiter

$$\sqrt{n}(\sqrt{n+1} - 1) \leq \sqrt{n} \frac{3}{n^{1/6}} = \frac{3}{n^{1/6}}$$

Es gilt

$$\lim_{n\to\infty} \frac{3}{n^{1/6}} = 3\lim_{n\to\infty} \frac{1}{n^{1/6}} = 0$$

weil für jedes $\varepsilon > 0$ kann man $N := \lceil\frac{1}{\varepsilon^6}\rceil + 1$ setzen, so dass für alle $n \geq N$ gilt:

$$\frac{1}{n^{1/6}} < \varepsilon$$

Nach der Behauptung 1 mit $a_n = \sqrt{n}(\sqrt{n+1} - 1)$, $b_n = \frac{3}{n^{1/6}}$ und $N_0 = 3$ gilt

$$\lim_{n\to\infty} \sqrt{n}(\sqrt{n+1} - 1) = 0$$
