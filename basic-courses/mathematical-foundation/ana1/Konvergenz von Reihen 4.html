Konvergenz von Reihen 4

Sei $\sum_{n=1}^{\infty} a_n$ eine Reihe. Nehmen Sie an, dass ein $0 < \theta < 1$ und ein $n_0 \in \mathbb{N}$ existieren, so dass

$$\sqrt[n]{|a_n|} \leq \theta \text{ für alle } n \geq n_0$$

a) Beweisen Sie, dass $\sum_{n=1}^{\infty} a_n$ absolut konvergiert.

b) Zeigen Sie, dass die Bedingung

$$\sqrt[n]{|a_n|} < 1 \text{ für alle } n \geq n_0$$

nicht hinreichend für die Konvergenz der Reihe $\sum_{n=1}^{\infty} a_n$ ist. Ist dies eine notwendige Bedingung?

Lösung

Zu a): Für alle $n \geq n_0$ gilt

$$\sqrt[n]{|a_n|} \leq \theta \iff |a_n| \leq \theta^n$$

Dies folgt einfach aus der Formel

$$a^n - b^n = (a-b)(a^{n-1}b^0 + ... + a^0b^{n-1}) \text{ für alle } a,b \in \mathbb{R}$$

Deshalb ist die Reihe $\sum_{n=1}^{\infty} \theta^n = \frac{1}{1-\theta} - 1$ eine konvergente Majorante für $\sum_{n=1}^{\infty} |a_n|$. Also konvergiert $\sum_{n=1}^{\infty} a_n$ absolut.

Zu b): Die harmonische Reihe

$$a_n := \frac{1}{n} \text{ für alle } n \in \mathbb{N}$$

erfüllt

$$\sqrt[n]{|a_n|} = \frac{1}{\sqrt[n]{n}} < 1 \text{ für alle } n \geq 2$$

Sie konvergiert aber nicht. Das zeigt, dass die Bedingung nicht hinreichend ist. Sei $\sum_{n=1}^{\infty} a_n$ eine konvergente Reihe. Dann ist

$$\lim_{n \to \infty} a_n = 0$$

Dies ist aber äquivalent zu

$$\lim_{n \to \infty} |a_n| = 0$$

Deshalb gibt es ein $n_0 \in \mathbb{N}$, so dass für alle $n \geq n_0$ gilt

$$|a_n| \leq \frac{1}{2}$$

und weiter

$$\sqrt[n]{|a_n|} \leq \frac{1}{\sqrt[n]{2}} < 1$$

Deswegen ist die Bedingung notwendig.
