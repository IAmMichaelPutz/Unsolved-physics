Aufgabe 3

Sei

$$a_n := \frac{1}{\sqrt{n}}$$

für alle $n \in \mathbb{N}$. Beweisen Sie, dass die Folge $(a_n)_{n\in\mathbb{N}}$ gegen 0 konvergiert.

Lösung

Wir müssen zeigen:

$$\forall\varepsilon > 0 \;\exists N \in \mathbb{N} \;\forall n \geq N: \left|\frac{1}{\sqrt{n}} - 0\right| = \frac{1}{\sqrt{n}} < \varepsilon$$

Sei $\varepsilon > 0$. Wir finden ein $N \in \mathbb{N}$, so dass

$$\frac{1}{\sqrt{N}} < \varepsilon \iff \sqrt{N} > \frac{1}{\varepsilon} \iff N > \frac{1}{\varepsilon^2}$$

Diese Ungleichung ist zum Beispiel erfüllt von

$$N := \left\lfloor\frac{1}{\varepsilon^2}\right\rfloor + 1$$

Für alle $n \geq N$ gilt jetzt:

$$\frac{1}{\sqrt{n}} \leq \frac{1}{\sqrt{N}} < \varepsilon$$

Weil $\varepsilon > 0$ beliebig ist, ist die Konvergenz von $\frac{1}{\sqrt{n}}$ gegen 0 dadurch gezeigt.
