Aufgabe 2a

Seien $\vec{x} = \begin{pmatrix} x_1 \\ x_2 \end{pmatrix}$ und $\vec{y} = \begin{pmatrix} y_1 \\ y_2 \end{pmatrix}$ Vektoren aus $\mathbb{R}^2$. Die euklidische Norm von $\vec{x}$ ist definiert als

$$\|\vec{x}\| := \sqrt{x_1^2 + x_2^2}$$

Die Summe von $\vec{x}$ und $\vec{y}$ ist definiert als

$$\vec{x} + \vec{y} := \begin{pmatrix} x_1 + y_1 \\ x_2 + y_2 \end{pmatrix} \in \mathbb{R}^2$$

a) Beweisen Sie mit Hilfe der Aufgabe 1 die Dreiecksungleichung für die euklidische Norm:

$$\|\vec{x} + \vec{y}\| \leq \|\vec{x}\| + \|\vec{y}\|$$

Lösung

Nach der Einsetzung der Definition lautet die Ungleichung

$$\sqrt{(x_1 + y_1)^2 + (x_2 + y_2)^2} \leq \sqrt{x_1^2 + x_2^2} + \sqrt{y_1^2 + y_2^2}$$

Wir machen folgende Umformungen:

$$\sqrt{(x_1 + y_1)^2 + (x_2 + y_2)^2} \leq \sqrt{x_1^2 + x_2^2} + \sqrt{y_1^2 + y_2^2} \quad /(..)^2$$ $$(x_1 + y_1)^2 + (x_2 + y_2)^2 \leq x_1^2 + x_2^2 + 2\sqrt{x_1^2 + x_2^2}\sqrt{y_1^2 + y_2^2} + y_1^2 + y_2^2$$ $$-(x_1^2+y_1^2+x_2^2+y_2^2)$$ $$2x_1y_1 + 2x_2y_2 \leq 2\sqrt{x_1^2 + x_2^2}\sqrt{y_1^2 + y_2^2} \quad /\frac{1}{2}(..)$$ $$x_1y_1 + x_2y_2 \leq \sqrt{x_1^2 + x_2^2}\sqrt{y_1^2 + y_2^2} \quad /(..)^2$$ $$(x_1y_1 + x_2y_2)^2 \leq (x_1^2 + x_2^2)(y_1^2 + y_2^2)$$ $$-(x_1^2y_1^2+x_2^2y_2^2)$$ $$2x_1y_1x_2y_2 \leq x_1^2y_2^2 + x_2^2y_1^2 \quad /\frac{1}{2}(..)$$ $$(x_1y_2)(x_2y_1) \leq \frac{1}{2}((x_1y_2)^2 + (x_2y_1)^2)$$

Die letzte Ungleichung folgt aber sofort aus Aufgabe 1 mit $x = x_1y_2$ und $y = x_2y_1$.
