Aufgabe 1

Bestimmen Sie die folgenden Grenzwerte:

$$\text{a) } \lim_{n\to\infty} \sqrt[n]{n}$$ $$\text{b) } \lim_{n\to\infty} \sqrt[n]{n^k} \text{ für alle } k \in \mathbb{N}$$

Lösung

Zu a): Nach Aufgabe 4.c auf Blatt 3 und Aufgabe 3 auf Blatt 2 gilt

$$\lim_{n\to\infty} \sqrt[n]{n} = \lim_{n\to\infty}(1 + (\sqrt[n]{n} - 1)) = 1 + \lim_{n\to\infty}\sqrt{n}(\sqrt[n]{n} - 1)\frac{1}{\sqrt{n}} = 1 + 0 \cdot 0 = 1$$

Zu b): Nach der Produktregel und Teilaufgabe a) gilt

$$\lim_{n\to\infty} \sqrt[n]{n^k} = \lim_{n\to\infty} (\sqrt[n]{n})^k = (1)^k = 1$$
