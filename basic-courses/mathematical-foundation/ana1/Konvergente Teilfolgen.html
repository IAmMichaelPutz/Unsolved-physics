Aufgabe 4

Sei $(a_n)_{n\in\mathbb{N}}$ eine Folge. Sei $(a_{n_k})_{k\in\mathbb{N}}$ eine konvergente Teilfolge von $(a_n)_{n\in\mathbb{N}}$. Beweisen Sie:

$$\text{a) } \liminf_{n\to\infty} a_n \leq \lim_{k\to\infty} a_{n_k} \leq \limsup_{n\to\infty} a_n$$

b) Es gibt konvergente Teilfolgen $(a_{m_k})_{k\in\mathbb{N}}$ und $(a_{p_k})_{k\in\mathbb{N}}$ von $(a_n)_{n\in\mathbb{N}}$, so dass gilt:

$$\lim_{k\to\infty} a_{m_k} = \limsup_{n\to\infty} a_n$$ $$\lim_{k\to\infty} a_{p_k} = \liminf_{n\to\infty} a_n$$

Lösung

Zu a): Für alle $k \in \mathbb{N}$ ist

$$A_{n_k} = \inf\{a_n | n \geq n_k\} \leq a_{n_k} \leq \sup\{a_n | n \geq n_k\} = A_{n_k}$$

Weil alle Teilfolgen einer konvergenten Folge zu demselben Grenzwert konvergieren, folgt jetzt die zu beweisende Aussage aus der doppelten Anwendung der Behauptung 1.

Zu b): Wir bezeichnen

$$a := \limsup_{n\to\infty} a_n$$

Wir werden $n_k$ für alle $k \in \mathbb{N}$ induktiv definieren. Zunächst setzen wir

$$n_1 := 1$$

Sei $k > 1$. Es wird angenommen, dass $n_1 < ... < n_{k-1}$ schon bestimmt waren. Wir definieren nun $n_k$. Sei $N \in \mathbb{N}$, so dass

$$N > \max\{n_1,...,n_{k-1}\}$$

und

$$a - \frac{1}{k} < \sup\{a_l | l \geq N\} < a + \frac{1}{k}$$

Insbesondere gibt es ein $l \geq N$, so dass

$$a - \frac{1}{k} < a_l < a + \frac{1}{k}$$

Sonst wäre nämlich $a - \frac{1}{k}$ eine kleinere obere Schranke von $\{a_l | l \geq N\}$. Wir setzen

$$n_k := l$$

Damit haben wir eine streng monoton steigende Folge $(n_k)_{k\in\mathbb{N}}$ konstruiert, so dass für alle $k \in \mathbb{N}$, $k \geq 2$ gilt

$$|a_{n_k} - a| < \frac{1}{k}$$

Daraus ergibt sich

$$\lim_{k\to\infty} a_{n_k} = a$$

Die Folge $(m_k)_{k\in\mathbb{N}}$ konstruiert man wie oben für die Folge $(-a_n)_{n\in\mathbb{N}}$. Dann gilt

$$\lim_{k\to\infty} a_{m_k} = -\lim_{k\to\infty}(-a_{m_k}) = -\limsup_{n\to\infty}(-a_n) = \liminf_{n\to\infty} a_n$$
