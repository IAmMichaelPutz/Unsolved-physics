5. Variationsprinzip (**)

a) Betrachten Sie eine Lagrange-Funktion L(q,q̇,q̈;t), die auch von der zweiten Zeitableitung von q abhängt. Zeigen Sie, dass die Euler-Lagrange-Gleichung für diese Funktion lautet:

\[ \left(\frac{\partial}{\partial q} - \frac{d}{dt}\frac{\partial}{\partial\dot{q}} + \frac{d^2}{dt^2}\frac{\partial}{\partial\ddot{q}}\right)L(q,\dot{q},\ddot{q};t) = 0 \]

wobei wir annehmen, dass weder q noch q̇ an den Endpunkten variiert werden, d.h. δq(t₁) = δq(t₂) = δq̇(t₁) = δq̇(t₂) = 0.

b) Zeigen Sie, dass die kürzeste Verbindung zwischen zwei Punkten (geodätische Linie) auf einer Kugel durch einen Großkreisbogen gegeben ist.

Lösung anzeigen

a) Variation der Wirkung:

\begin{align} \delta S[q] &= 0 \tag{1} \\ \Leftrightarrow \frac{d}{d\eta}S(\eta)\bigg|_{\eta=0} &= 0 \tag{2} \end{align}

Nach Anwendung der Variationsrechnung und zweimaliger partieller Integration:

\[ \int_{t_1}^{t_2}\left(\frac{\partial L}{\partial q} - \frac{d}{dt}\frac{\partial L}{\partial\dot{q}} + \frac{d^2}{dt^2}\frac{\partial L}{\partial\ddot{q}}\right)\delta q(t)dt = 0 \tag{3} \]

b) Geodäte auf der Kugel:

Linienelement auf einer Kugel mit Radius R:

\[ ds = R\sqrt{1 + \sin^2\vartheta\phi'^2}d\vartheta \tag{4} \]

Lagrange-Funktion:

\[ L(\phi,\phi';\vartheta) = \sqrt{1 + \sin^2\vartheta\phi'^2} \tag{5} \]

Da L unabhängig von φ ist, ist φ eine zyklische Koordinate und:

\[ p_\phi = \frac{\partial L}{\partial\phi'} = \frac{\sin^2\vartheta\phi'}{\sqrt{1 + \sin^2\vartheta\phi'^2}} = const \tag{6} \]

Für den ersten Punkt am Nordpol (ϑ = 0) gilt p_φ = 0, daher ist φ' = 0 und φ = const.

Folglich sind die Geodäten Großkreisbögen.
