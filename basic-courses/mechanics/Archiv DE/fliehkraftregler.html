Fliehkraftregler

Ein Punkt m₂ bewegt sich entlang einer vertikalen Achse und ist durch einen masselosen Stab der Länge R mit zwei Massen m₁ verbunden. Das System ist am Punkt A durch zwei weitere masselose Stäbe der Länge R aufgehängt und rotiert mit konstanter Winkelgeschwindigkeit ω um die Achse. Die Massenpunkte unterliegen der Schwerkraft.

1. Wählen Sie ϑ als verallgemeinerte Koordinate. Bestimmen Sie die Lagrange-Funktion des Systems.

2. Sei m₂ = 0. Zeigen Sie, dass ϑ die folgende Bewegungsgleichung erfüllt:

\[ \ddot{\vartheta} = \left(\omega^2\cos(\vartheta) - \frac{g}{R}\right)\sin(\vartheta) \tag{1} \]

3. Welche Bedingung muss die Winkelgeschwindigkeit ω erfüllen, damit sich der Fliehkraftregler aufrichtet, d.h. damit ϑ = 0 instabil gegen kleine Störungen wird? Entwickeln Sie die Bewegungsgleichung um ϑ = 0 bis zur zweiten Ordnung.

Lösung anzeigen

Teil 1:

Für z₁ = R cos(ϑ), z₂ = 2R cos(ϑ) ⇒ \(\dot{z}_2 = -2R\dot{\vartheta}\sin(\vartheta)\)

\begin{align} T &= 2\cdot\frac{m_1}{2}(R^2\sin^2(\vartheta)\omega^2 + R^2\dot{\vartheta}^2) + \frac{m_2}{2}\dot{z}_2^2 \tag{2} \\ &= m_1(R^2\sin^2(\vartheta)\omega^2 + R^2\dot{\vartheta}^2) + 2m_2R^2\dot{\vartheta}^2\sin^2(\vartheta) \tag{3} \end{align}

Setzen des Nullpunkts des Gravitationspotentials auf die Höhe von Punkt A:

\[ U = -2m_1gz_1 - m_2gz_2 = -2m_1gR\cos(\vartheta) - 2m_2gR\cos(\vartheta) \tag{4} \]

Teil 2:

Für m₂ = 0 wird die Bewegungsgleichung zu:

\[ 2m_1R^2\ddot{\vartheta} - 2m_1R^2\omega^2\sin(\vartheta)\cos(\vartheta) + 2m_1gR\sin(\vartheta) = 0 \tag{5} \]

Teil 3:

Entwicklung um ϑ = 0:

\begin{align} \ddot{\vartheta} &\approx (\omega^2 - \frac{g}{R})\vartheta \tag{6} \\ \ddot{\vartheta} + (\frac{g}{R} - \omega^2)\vartheta &= 0 \tag{7} \end{align}

Für \(\frac{g}{R} - \omega^2 > 0\) entspricht dies einem harmonischen Oszillator, die Kraft wirkt der Auslenkung von ϑ = 0 entgegen ⇒ stabil gegen Auslenkungen!

Für \(\frac{g}{R} - \omega^2 < 0\) unterstützt die Kraft die Auslenkung ⇒ instabil gegen Auslenkungen, der Fliehkraftregler richtet sich für \(\omega^2 > \frac{g}{R}\) auf!
