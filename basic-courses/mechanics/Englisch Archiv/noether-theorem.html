4 Noether's Theorem

Consider the Lagrange function of a particle in a homogeneous magnetic field \(\mathbf{B} = B\mathbf{e}_z\):

\[ \mathcal{L} = \frac{m}{2}(\dot{x}^2 + \dot{y}^2 + \dot{z}^2) - \frac{eB}{2}(x\dot{y} - y\dot{x}) \tag{1} \]

and the infinitesimal transformation

\begin{align} x &\Rightarrow \tilde{x} = x - \epsilon y \tag{2} \\ y &\Rightarrow \tilde{y} = y - \epsilon x \tag{3} \\ z &\Rightarrow \tilde{z} = z \tag{4} \\ t &\Rightarrow \tilde{t} = t \tag{5} \end{align}

Show that the quantity \(m(x\dot{y} - y\dot{x}) - \frac{eB}{2}(x^2 + y^2)\) is a conserved quantity.

Show Solution

First, we verify that the Lagrange function remains invariant under the transformation.

\begin{align} \tilde{T} &= \frac{m}{2}((\dot{x} - \epsilon\dot{y})^2 + (\dot{y} - \epsilon\dot{x})^2 + \dot{z}^2) \tag{6} \\ &= \frac{m}{2}(\dot{x}^2 - \epsilon\dot{x}\dot{y} + \dot{y}^2\epsilon^2 + \dot{y}^2 - \epsilon\dot{x}\dot{y} + \dot{x}^2\epsilon^2 + \dot{z}^2) = T \tag{7} \end{align}

Here, the quadratic terms in ε were neglected (ε ≪ 1)

\begin{align} \tilde{U} &= \frac{eB}{2}((x - \epsilon y)(\dot{y} - \epsilon\dot{x}) - (y - \epsilon x)(\dot{x} - \epsilon\dot{y})) = U \tag{8} \\ \tilde{\mathcal{L}} = \tilde{T} - \tilde{U} &= \frac{m}{2}(\dot{x}^2 + \dot{y}^2 + \dot{z}^2) - \frac{eB}{2}(x\dot{y} - y\dot{x}) = \mathcal{L} \tag{9} \end{align}

Thus, the Lagrange function is indeed invariant. We can now apply Noether's theorem, using the notation from the lecture. (ψ₁ = -y; ψ₂ = x; ψ₃ = 0; φ = 0)

\[ Q = \sum_{i=1}^3 \frac{\partial\mathcal{L}}{\partial\dot{q_i}}\psi_i = \frac{\partial\mathcal{L}}{\partial\dot{x}}\psi_1 + \frac{\partial\mathcal{L}}{\partial\dot{y}}\psi_2 + \frac{\partial\mathcal{L}}{\partial\dot{z}}\psi_3 \tag{10} \]

Substituting and simplifying yields the claimed conservation law.
